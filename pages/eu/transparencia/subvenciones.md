# <span aria-hidden="true">💶</span> Diru-laguntzak

<EnConstruccion motivo="Diru-laguntzen Datu-base Nazionalak API publiko bat du, baina administrazio guztien milioika emakida itzultzen ditu, orrikatuta; zatika deskargatu, emaile den organo bakoitza administrazioaren arabera sailkatu eta kategoriak garbitu behar dira zifrak argitaratu aurretik." />

## Zer erakutsiko duen

Diru-laguntzen Lege Orokorrak **norgehiagoka lehia** ezartzen du arau gisa: deialdi publikoa eta
irizpideen araberako banaketa. Salbuespenak diru-laguntza **izendunak** dira (aurrekontuetan izenez
jasotakoak) eta interes publikoko arrazoiengatik **zuzeneko emakida** bidez emandakoak. Atal honek honako
hauek neurtuko ditu:

- Diru-laguntzen diruaren zer zati ematen den lehiarik gabe, administrazioka eta urteka.
- Organo emaile eta onuradun nagusiak (pertsona juridikoak; pertsona fisikoen daturik inoiz ez).
- Horien bilakaera euro errealetan eta biztanleko, eta diru-laguntzak ematen dituen Gobernuaren **alderdiaren
  araberako** alderaketa.

## Nondik aterako diren datuak

- [Diru-laguntzen Datu-base Nazionala (BDNS) / Diru-laguntzen eta Laguntza Publikoen Publizitate Sistema
  Nazionala](https://www.infosubvenciones.es/bdnstrans/GE/es/index), administrazio guztien deialdi eta
  emakidekin, gutxi gorabehera 2016tik, bere API publikoaren bidez eskuragarri.

Bitartean, [datu irekien proiektuen zerrendak](/eu/varios/datos-abiertos) iturri hori biltzen du.
