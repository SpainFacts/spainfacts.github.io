# <span aria-hidden="true">💶</span> Subvencions

<EnConstruccion motivo="la Base de Dades Nacional de Subvencions té una API pública, però retorna milions de concessions paginades de totes les administracions; cal descarregar-les per trams, classificar cada òrgan concedent per administració i netejar les categories abans de publicar xifres." />

## Què mostrarà

La Llei general de subvencions fixa com a regla la **concurrència competitiva**: convocatòria pública i
repartiment segons criteris. Les excepcions són les subvencions **nominatives** (amb nom als
pressupostos) i les de **concessió directa** per raons d'interès públic. Aquesta secció mesurarà:

- Quina part dels diners de subvencions es concedeix sense concurrència, per administració i per any.
- Els principals òrgans concedents i beneficiaris (persones jurídiques; mai dades de persones
  físiques).
- La seva evolució en euros reals per habitant i la comparació **per partit** del Govern que les concedeix.

## D'on sortiran les dades

- [Base de Dades Nacional de Subvencions (BDNS) / Sistema Nacional de Publicitat de Subvencions i Ajuts
  Públics](https://www.infosubvenciones.es/bdnstrans/GE/es/index), amb convocatòries i concessions de
  totes les administracions des de 2016 aproximadament, accessibles per la seva API pública.

Mentrestant, la [llista de projectes de dades obertes](/ca/varios/datos-abiertos) recull aquesta font.
